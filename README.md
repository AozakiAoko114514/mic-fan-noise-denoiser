# 麦克风风扇噪声降噪器

> 给**风扇 / 空调这类稳态机器噪声**准备的 Windows 实时降噪虚拟麦克风：用你机器上**实测出来的噪声特征**做定点清除，而不是丢给一个通用模型去猜。

## 📌 项目简介

《麦克风风扇噪声降噪器》是一款**纯本地**的实时降噪工具：它先在你自己的机器上测量噪声（笔记本风扇、外置散热器、空调、机箱风扇等稳态噪声）的频谱特征，然后在麦克风和游戏 / 会议软件之间插入一条降噪链，对外提供一路"虚拟麦克风"。

它**不联网、不上传、不调用任何云服务**，全部计算在本地 CPU 完成，也不写注册表、不装驱动。

**为什么不用现成的 AI 降噪？**

NVIDIA Broadcast / Krisp / RNNoise 这类通用模型对"未知噪声"很强，但面对**固定不动的稳态噪声源**时有两个问题：

1. 它们是黑盒：为了压掉窄带尖峰，常常把整段人声一起削薄，听起来发闷；
2. 走 GPU 的方案会跟游戏抢显卡，并把独显一直钉在高功耗状态。

本项目反过来做——**先测量，再定点清除**：噪声的离散谐波用窄带陷波精确挖掉，宽带底噪用过减维纳滤波压制，并且**跑在 CPU 的 E 核上**，对游戏帧率的影响≈0。

## ✨ 功能列表

**降噪引擎**

- 实测谐波陷波组：把噪声里的离散尖峰（风扇转动基频、叶片通过频率及其谐波）精确挖掉，不牵连人声
- 自适应过减谱减：滑动最小值噪声估计（可自愈，不需要提前录底噪），配合维纳式过减增益与帧间 / 频间增益平滑
- 帧级软噪声门：说话间隙彻底静音，且连续过渡、不斩字
- 全向量化 numpy 实现，没有逐样本 Python 循环

**虚拟麦克风**

- WASAPI 采集 + 回放，算法延迟约 64 ms（可切 32 / 64 / 128 ms）
- 输出送进 Voicemeeter 虚拟输入，任意应用（游戏 / 会议 / 直播 / 录制）都能把它当麦克风选
- **自动完成 Voicemeeter 路由配置并实测验证**：它的 8 路虚拟设备友好名完全相同、靠名字无法区分，工具用"播测试音 + 回录"自动判定是哪一路
- 设备选择自动识别并持久化到 `config.json`

**性能**

- 纯 CPU，完全不占显卡
- 进程绑定到 **E 核（能效核）+ 低于普通优先级**，不与游戏抢 P 核
- 单线程实时因子 RTF ≈ 0.008（约 125 倍实时）

**验证与调参**

- 离线客观测试：合成语音 + 实测噪声 → 噪声抑制量、语音损伤、ΔSNR、实时因子、安全自检
- 端到端验证：麦克风 → 降噪 → 虚拟麦克风，直接在虚拟麦克风上实测压制量
- 实时对比工具：一眼确认"管线到底有没有在工作"
- 噪声测量工具：分析 10 秒录音，直接输出可粘贴的陷波参数表

**一键管理**

- 启动 / 停止 / 状态 / 实时对比 / 重新探测设备 / 查看日志 / 还原 Voicemeeter 参数
- 关掉管理器窗口后管线继续运行；重复点"启动"不会起两份
- 全部回滚：删文件夹即彻底移除

所有结论都有实测支撑，不是"应该有效"。

**离线客观测试**（合成语音 + 真实录制的风扇噪声）

| 指标 | 结果 |
| --- | --- |
| 噪声抑制（稳态段） | **−34.4 dB** |
| ΔSNR（目标信噪比 30 / 20 / 10 dB） | +10.7 / +11.1 / +10.6 dB |
| 谐波突出度 | 363 Hz：6.4 → 1.7 dB |
| 实时因子（单线程） | 0.008 |
| 安全自检 | 无 NaN/Inf、无削顶 |

**端到端**（真实实时采集，经 Voicemeeter，在虚拟麦克风上测量）

```
原始麦克风   −56.7 dBFS
虚拟麦克风   −91.3 dBFS      →  压制 −34.7 dB
```

复现：

```bat
python denoise\tests\offline_test.py       :: 离线客观测试 + 参数扫描

```

## 📖 使用方法

### 1. 安装依赖

```bat
pip install -r requirements.txt
```

还需要安装 **Voicemeeter Potato**（免费，提供虚拟麦克风）。

### 2. 测量你自己的噪声

录 10 秒噪声（**保持安静**，让风扇正常转）：

```bat
python denoise\live.py --ab 10
python denoise\tools\measure_noise.py denoise\samples\ab_1_raw.wav
```

`measure_noise.py` 会输出频段能量分布、稳态性、以及最强的谐波峰，并直接给出一份可粘贴的 `harmonics` 参数。手头没有录音时，可以先生成一份合成样本：

```bat
python denoise\tools\make_noise_sample.py
```

### 3. 配置虚拟麦克风

启动 Voicemeeter，然后让工具自己完成配置与验证：

```bat
python denoise\tools\vm_setup.py
```

它会打开虚拟输入条的 B1 总线、关掉所有 A1~A5 硬件监听（防啸叫）、静音硬件输入条，并打印出"**往哪个输出送、应用该从哪个设备取**"。

### 4. 启动

```bat
python denoise\live.py --run            :: Ctrl+C 停止
```

或者用一键管理器：

```bat
python manager\manager.py               :: [1] 启动，[4] 实时验证，[2] 停止
```

Windows 上也可以直接双击 `manager\start-all.cmd`。

### 5. 让应用使用虚拟麦克风

在游戏 / 会议软件里把麦克风选成上一步报告的那个录音设备（例如 `Voicemeeter Out 6`）。

> 💡 多数游戏只在启动时枚举音频设备，**改完要重启游戏**。

## 🔧 参数与调参

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--n-fft` | 4096 | 4096 = 64 ms 延迟 / 11.7 Hz 频点；2048 = 32 ms（陷波精度下降）；8192 = 128 ms |
| `--bias` | 2.5 | 噪声估计偏差。**越大压得越狠**（离线扫描：1.5→4.0 使稳态压制从 −13 dB 到 −37 dB，而语音包络损伤指标无变化） |
| `--over` | 2.5 | 过减因子 |
| `--gate` | 6.0 | 噪声门阈值（帧信噪比 dB） |
| `--gate-floor` | −16 | 门全关时的增益（dB） |
| `--no-gate` | — | 关闭噪声门（如果觉得吞字） |
| `--affinity` | 自动 | CPU 亲和性掩码；逻辑处理器 ≥32 时自动绑 E 核 |

`harmonics` 是 `(频率Hz, 半带宽Hz, 深度dB)` 列表，**必须按你自己的机器重测**——风扇转速不同，谐波位置就不同。

## ⚠️ 已知限制

- **固定频率陷波只适用于转速稳定的风扇**。转速变化时谐波会移开，真正兜底的是自适应谱减（它跟随任意稳态噪声）。
- **做不到波束成形**。厂商驱动通常只暴露阵列处理后的立体声流（参考机器两声道相关性 0.92），除非设备能给出原始多通道，否则 DOA / 波束成形无从下手。
- **启动有约 2 秒收敛期**（滑动最小值窗口填充），这段时间相当于直通。
- **Voicemeeter 必须常驻**，退出后虚拟麦克风断开。
- 独占模式（ASIO）的应用程序无法使用虚拟麦克风。
- 仅支持 Windows（WASAPI + Voicemeeter）。
